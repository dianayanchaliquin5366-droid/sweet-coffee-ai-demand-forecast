# Sweet Coffee AI Demand Forecast

## Descripción

Este proyecto utiliza una arquitectura organizada por agentes para dividir las responsabilidades del desarrollo, análisis de datos, predicción de demanda y documentación.

## Agentes principales

### Agent Data Analyst
**Responsabilidad:**
- Preparar y organizar los datos.
- Validar la estructura de la información.
- Gestionar los datos simulados utilizados en el proyecto.

### Agent Forecast AI
**Responsabilidad:**
- Analizar el comportamiento de la demanda.
- Generar predicciones de ventas.
- Apoyar el proceso de pronóstico mediante inteligencia artificial.

### Agent Frontend Developer
**Responsabilidad:**
- Desarrollar la interfaz web con React y Vite.
- Implementar el dashboard y los componentes visuales.
- Integrar la información proveniente del backend.

### Agent Backend Developer
**Responsabilidad:**
- Desarrollar la API del sistema.
- Gestionar las rutas y servicios.
- Facilitar la comunicación entre el frontend y la lógica del servidor.

### Agent Documentation
**Responsabilidad:**
- Mantener la documentación técnica del proyecto.
- Actualizar el README.
- Registrar las evidencias y el proceso de desarrollo.

## Flujo de trabajo

1. Preparación de datos.
2. Análisis y predicción de demanda.
3. Procesamiento mediante la API.
4. Visualización de resultados en el dashboard.
5. Documentación y mantenimiento del proyecto.

## Tecnologías utilizadas

- React
- Vite
- Node.js
- Express
- GitHub
- Vercel

## Objetivo

Desarrollar una solución basada en inteligencia artificial para apoyar el pronóstico de la demanda en una cafetería, facilitando la toma de decisiones mediante un dashboard interactivo.
