# Agents List

## Agent Data Analyst
Responsable de la organización, validación y preparación de los datos utilizados por el sistema.

## Agent Forecast AI
Encargado del análisis predictivo y del proceso de pronóstico de demanda.

## Agent Frontend Developer
Responsable del desarrollo de la interfaz web utilizando React, Vite y Material UI.

## Agent Backend Developer
Responsable de la implementación de la API y la comunicación entre el frontend y el backend.

## Agent Documentation
Encargado de mantener la documentación técnica, evidencias y manuales del proyecto.
