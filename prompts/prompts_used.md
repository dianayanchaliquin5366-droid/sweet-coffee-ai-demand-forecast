# Prompts Used

Durante el desarrollo del proyecto se utilizaron prompts para apoyar las siguientes actividades:

- Diseño de la arquitectura del sistema.
- Desarrollo del dashboard en React.
- Implementación de la API en Node.js.
- Generación de componentes reutilizables.
- Elaboración de documentación técnica.
- Organización de la estructura del proyecto.
- Preparación de evidencias para la entrega final.
